# CommenSup

Python tools for finding commensurate supercells for twisted bilayer heterostructures and writing VASP POSCAR files.

## Installation

From this folder, install the required packages:

```sh
python -m pip install -r requirements.txt
```

## Example

See `run.ipynb` for an example of searching for a supercell and generating a POSCAR file. Open the notebook in your preferred Jupyter-compatible editor and run the cells in order.

If you need a notebook interface, install and launch JupyterLab:

```sh
python -m pip install jupyterlab
jupyter lab run.ipynb
```
